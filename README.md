# 低重叠点云配准

3D Vision 课程项目的开题材料、数据协议核查与真实点云样例。当前尚未训练或运行配准模型。

- 演示稿：`proposals/low_overlap_registration_proposal.pptx` / `.pdf`。
- 样例图：`proposals/examples/`。
- 构建脚本与使用说明：`proposals/v2/`。
- 点云样例、渲染脚本与来源记录：`proposals/v2/assets/registration/`。
- 配准元数据及审计结果：`proposals/research/`。

在安装 Microsoft PowerPoint 的 Windows 环境中，可运行 `proposals/build_proposals.ps1` 重新导出演示稿。该操作会更新现有 PPTX、PDF 和预览图；运行前请保存手动修改。

仓库不包含课程 Lecture 讲义、独立的 GraspNet 历史素材或临时检查图。现有材料中提到的 `dataset_audit_zh.txt` 混有 GraspNet 历史调研，因此未上传；配准专项审计保留在 `proposals/research/`。点云素材的来源与校验记录见各目录中的 manifest 文件。
